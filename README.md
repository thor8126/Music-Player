# Music-Player by lakhabhayi@gmail.com(Github:thor8126)

A simple music player made with Spotify API and Node.js. Still in development.

# Instructions
1. Clone the repository
2. Run npm install
3. Run npm start
4. Open localhost:3000 in your browser


# Features
1. Search for songs
2. Play songs(can play only 30 seconds of a song due to Spotify API restrictions for free accounts)
3. Pause songs
4. Add to favourites
5. Remove from favourites
6. View favourites

# Bugs
1. Songs can be played only for 30 seconds due to Spotify API restrictions for free accounts
2. Songs can be played only once due to Spotify API restrictions for free accounts
3. Songs can be played only in the browser due to Spotify API restrictions for free accounts
4. If song is not playing, try refreshing the page or play another song because of Spotify API restrictions for free accounts
